PARTS BIN — CLOUD SYNC SETUP (PC ↔ phone)
==========================================

This makes your inventory sync automatically across devices using a free
Google Firebase database. The app still works offline; sync turns on only
once you paste your details into Settings → Cloud sync.

You do this ONCE. Takes about 10 minutes.

------------------------------------------------------------
PART 1 — Make a free Firebase project (one time)
------------------------------------------------------------
1. Go to  https://console.firebase.google.com  and sign in with a Google account.
2. Click "Create a project" (or "Add project").
   - Give it any name (e.g. "parts-bin").
   - You can turn OFF Google Analytics. Click Create.
3. In the left menu click  Build → Firestore Database  →  Create database.
   - Choose "Start in test mode" (we'll tighten it in Part 4). Pick any location. Enable.
4. Click the gear (Project settings) at top-left → scroll to "Your apps".
   - Click the  </>  (Web) icon. Give it a nickname, click "Register app".
   - You'll see a block of code with  const firebaseConfig = { apiKey: "...", ... }.
   - COPY just the  { ... }  part (the object inside the curly braces, including the braces).

------------------------------------------------------------
PART 2 — Connect the app on your PC
------------------------------------------------------------
5. Open Parts Bin → ⚙ Settings → "Cloud sync".
6. Paste the  { ... }  config into the big box.
7. In the "secret sync code" box, type a long private phrase you'll remember,
   e.g.  troys-parts-bin-9f3k2x   (use the SAME on every device — treat it like a password).
8. Click  Connect.  It should say "Connected — syncing".
   Your current data is now uploaded to the cloud.

------------------------------------------------------------
PART 3 — Use it on your phone
------------------------------------------------------------
Your phone needs the app at a web address. Easiest free way:
9. On your PC go to  https://app.netlify.com/drop
10. Drag BOTH files onto that page together:  "Parts Bin.html"  AND  "zxing.min.js".
    (Tip: rename "Parts Bin.html" to  index.html  before dragging so it opens by default.)
11. Netlify gives you a link like  https://something.netlify.app  — open that on your phone.
12. On the phone: ⚙ Settings → Cloud sync → paste the SAME config and the SAME sync code → Connect.

Now any change on either device shows up on the other within a second or two.

------------------------------------------------------------
PART 4 — Lock it down (recommended)
------------------------------------------------------------
Test mode lets anyone read/write for 30 days. To keep it private:
- In Firestore → Rules, replace with:

    rules_version = '2';
    service cloud.firestore {
      match /databases/{database}/documents {
        match /partsbin/{doc} {
          allow read, write: if true;
        }
      }
    }

  Your data is protected by your secret sync code (keep it private and long).
  For stronger security later, ask me about adding a login.

------------------------------------------------------------
NOTES
------------------------------------------------------------
• Needs internet to sync; offline changes upload next time you're online.
• Whichever device saved most recently wins if you edit the same thing on two
  devices at once — so avoid editing the same item on both at the same moment.
• Photos are stored too; lots of large photos use more of the free quota.
